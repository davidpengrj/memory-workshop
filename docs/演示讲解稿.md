# 拾光工坊 · 宫保鸡丁队演示讲解稿

队长：彭然君；队友：杨睿。

## 1. 拾光工坊：让回忆用手边材料落地

大家好，我们是宫保鸡丁队，作品叫拾光工坊。想把回忆做成礼物，难点常常出现在图画好之后：材料放不下，细节太脆，也不知道怎么交给机器制作。我们把情感设计和制作准备连在一起，从一段故事，走到一份可以交接的生产包。

## 2. 真实 Kiro 调用，把回忆组织成分层场景

这里输入一段关于外婆小院的回忆，点击生成。我们实际调用已连接的 Kiro，由它选择场景、图形和构图，再由几何引擎生成六层轮廓。结果可以旋转、展开，也可以调整尺寸。当前支持四类场景和十二种意象，是受约束的情感设计工具。

## 3. 有限库存，会让原方案真正失败

接下来进入生产工作台。这里有四张窄余料和四张新板，库存数量是有限的。十八厘米的原方案使用五个完整间隔框，当前排版还有三个零件放不下，生产包不能导出。系统不会偷偷增加板材，也不会把超出设备工作区的板材当作可用。

## 4. 改变间隔框结构，让窄余料重新可用

点击按库存找可行方案，系统比较尺寸和结构。它把五个整框改为二十根拼接条，窄余料就能参与制作。这个演示中，十八厘米的作品保持原尺寸，二十六个零件全部排入，使用三张新板和四张余料。代价是增加胶粘和定位步骤，实际强度仍要试做。

## 5. 需求变化，重新寻找可行方案

如果想做二十二厘米，系统会根据相同库存建议十八厘米。如果数量变成两件，它会再建议十四厘米，并核对五十二个零件。这是可复算的本地候选搜索，不额外消耗 AI 额度。规则优先保留较大的作品，再比较新板数量和板面占用，不宣称全局最优。

## 6. 细节体检与真实轮廓加固

制作前，细节体检高亮疑似过细的连接、尖端和小孔。选择零点八毫米加固后，预览与导出使用的实际轮廓一起变化，可以观察疑似薄弱区域的变化。加固也可能缩小或封闭小孔，所以软件保留提示。这是几何估计，不能代替材料强度和实体试切。

## 7. 把试切结果留下来，而不是反复猜参数

切缝记录使用三十毫米外片和十毫米方孔，做双向测量。这里输入的是演示假设：外片二十九点八，方孔十点二，得到零点二毫米估计。两次测量不一致时会提示复测。数据按材料保留，也会进入生产包；当前没有自动施加切缝补偿。

## 8. 激光故事层 + 3D 打印底座，一包交接

展示底座根据板厚和装配余量生成真实的三维模型。假设板厚二点八毫米，十一层加余量，槽宽就是三十一点四毫米。最后下载生产包，包含已排版的整板图纸、零件定位表、底座模型、校准片和装配说明。底座可按 STL 格式导入切片软件，批量订单同步记录打印数量。

## 9. 从“好看的设计”，走向“可以试做的礼物”

我们希望服务创想三维用户从创意到第一次制作的那一步：让 Falcon 激光设备和三维打印围绕同一件礼物协作，让余料也能再次被使用。原型已经通过五十七项自动化检查和完整浏览器流程验证。我们目前没有硬件，尚未实体加工，也不把演示数据当作实际节省。谢谢。

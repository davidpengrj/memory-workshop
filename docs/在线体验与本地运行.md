# 在线体验与本地运行

公开体验入口：https://davidpengrj.github.io/memory-workshop/

## 在线体验版

无需登录或安装软件。选择三份示例中的任意一份，可调整配色、尺寸与材料，查看三维分层，比较有限库存下的可行方案，并下载 SVG、STL、零件表和生产交接单。草稿和库存设置保存在访问者自己的浏览器里。

在线版明确标记为示例体验，自定义故事输入为只读；不请求 AI 接口、不消耗 Kiro 额度。网页只分发浏览器运行所需的静态文件，GitHub Pages 不运行本地 Kiro 后端。

## 自定义故事生成

从 [Release](https://github.com/davidpengrj/memory-workshop/releases/tag/v2.1.1) 下载本地版，按照 [README](../README.md) 启动。已安装并登录的 Kiro CLI 用于真实 AI 生成，使用体验者自己的账号额度。本地版与在线版共用设计、排版和导出逻辑。

## 部署方式

- `npm run build`：本地完整版，输出至 `dist`，继续使用 Node 服务。
- `npm run build:demo`：免登录在线体验版，输出至 `dist-demo`，资源路径为 `/memory-workshop/`。
- `.github/workflows/pages.yml`：主分支的应用、依赖或部署配置变化时，安装锁定依赖、运行测试并部署 GitHub Pages；也可手动触发。

发布仅包含 `dist-demo`。线上构建不包含本地服务器、Kiro 登录信息或报名邮箱。

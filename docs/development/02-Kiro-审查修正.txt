## Tradeoffs

- Adding a `distDir` option is a minimal API surface addition to `createServer`; it keeps the static test deterministic and independent of whether the frontend has been built. Default behavior is unchanged.
- The unbalanced-brace scanner returns the trailing slice and the caller resumes at `start + 1`; this is O(n²) worst case on pathological brace-heavy input, but CLI output is small and bounded (256KB cap), so it's acceptable and simpler than a full tokenizer.
- The stderr drain keeps only a byte counter, not the text, honoring the contract's "no personal story in logs" while still preventing pipe backpressure.
- The disconnect test relies on timing (`setTimeout`) to sequence connect → start planner → disconnect; I kept margins generous (100ms/150ms) to reduce flakiness without slowing the suite much.
- I left `localhost` vs `127.0.0.1` treated as distinct authorities (exact host match), which is stricter; the demo and tests use one consistent origin, so this is safe and avoids widening the guard.

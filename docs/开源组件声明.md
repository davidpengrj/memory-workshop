直接依赖用途：React/React DOM 用于界面；Three.js 用于三维预览；polygon-clipping 用于几何布尔运算；clipper-lib 用于轮廓偏移、细节检查与轮廓加固；JSZip 用于制造包；Lucide 提供图标；Vite 构建。表中也列出顶层可见的传递依赖及 clipper-lib 内嵌的 JSBN。作用域内构建依赖与完整依赖关系见 package-lock.json，其原始许可证随 npm 包保留。

clipper-lib 原库版权归 Angus Johnson（2010–2017），JavaScript 移植署名 Timo；其大整数实现内嵌 Tom Wu 的 JSBN 子集，另行保留该组件许可。已保存源码头部版权与归属声明 [clipper-lib-NOTICE.txt](licenses/clipper-lib-NOTICE.txt)、[Boost 许可全文](licenses/clipper-lib-LICENSE.txt) 和 [JSBN 许可全文](licenses/clipper-lib-JSBN-LICENSE.txt)。Boost 原文来自 [Boost 官方许可证](https://www.boost.org/LICENSE_1_0.txt)；JSBN 原文于 2026-09-19 从[作者 Stanford 主页](http://www-cs-students.stanford.edu/~tjw/jsbn/LICENSE)取得。JSBN 是嵌入源码组件，不是另一个 npm 安装项；其完整版权与免责声明随项目保留。

界面通过 Google Fonts 加载 DM Sans 和 Noto Serif SC（SIL Open Font License 1.1），网络不可用时回退到系统字体；没有将这些字体二进制打入项目。系统字体按使用设备已有授权显示。

预置场景为本项目程序化轮廓，未复制赛题 PDF 的图片、雕刻文件或具体设计。城市拱门是概括性意象，不声称是大三巴的精确复原。示例故事为虚构演示文案。

演示配音使用本机系统语音合成，不模仿任何参赛成员或特定真人。测试浏览器与视频编码使用 Playwright/Chromium 和 FFmpeg，未将其二进制包含在源码包中。
